Composition and shared state

Inside each island, a value travels Parent → Child → Grandchild as props and a callback travels back up (prop drilling, in that framework's own idiom). Across islands, nothing is shared by default, so all of them subscribe to one tiny store. Change it here, in plain JavaScript, or from any card's +1 button, and every framework re-renders.
