The same nesting, with nanostores

This is the all-ten chain again, but the shared state is a pair of nanostores: an atom for the count and a computed store for its double. Each level reads them through that framework's adapter where one exists, and the header of every level says which glue it used. The earlier tabs use a hand-written store, so you can compare the two.
