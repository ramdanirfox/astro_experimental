Cross-framework nesting

Here the frameworks wrap each other, not just themselves. The nesting is written in Astro: each wrapper renders its children (a slot) and the next framework sits inside it. Every island is still its own island with its own runtime.

Shared store 0

Props

Come from Astro at each level and are static. A wrapper cannot pass props to its slotted child, because the child arrives as finished HTML.

Reactivity

Comes from the shared store. Every level shows the same count; any store +1 button, or the bar above, updates all of them.

Local state

local +1 re-renders only that level. The islands nested inside should survive it.
