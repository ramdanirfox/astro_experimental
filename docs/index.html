One page, nine UI approaches, and an htmx layer

Each card is an independent island using a different framework or library. The counters behave the same on purpose; what differs is how each one gets its HTML and when its JavaScript runs. htmx, below the cards, works across all of them.

htmx: a layer, not a framework

htmx is just HTML attributes (hx-get, hx-target) that fetch HTML from the server and swap it in. It does not know or care which framework produced the page, so it works next to all of the cards above. (For islands that render in the browser, call htmx.process(el) after they render so htmx notices the new attributes.)

Pick a framework: its description is fetched as an HTML fragment.
Fetched live from the server; needs the Node server.
